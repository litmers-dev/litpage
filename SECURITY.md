# Security policy

## Supported versions

Security fixes are provided for the latest commit on `main`.

## Report a vulnerability

Open the repository’s **Security** tab and select **Report a vulnerability** to submit a private report through GitHub. Include the affected commit or version, the impact, and steps to reproduce the issue. Maintainers assess every report using the same criteria.

Please allow 90 days from submission before publicly disclosing the vulnerability so maintainers have time to investigate and prepare a fix.
